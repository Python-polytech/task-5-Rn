# Фабрика классов PointN с кэшированием

Функция-фабрика `make_point_class(n, name=None)` динамически создаёт класс `PointN`
с ровно `n` координатами `x0, x1, …, x(n-1)`. Каждая координата управляется
дескриптором `CoordDescriptor`, который проверяет тип значения. Сами классы
кэшируются через `functools.lru_cache`, поэтому повторные вызовы для одного и
того же `n` не создают класс заново.

После запуска в консоль будет выведен результат работы фабрики: созданные

и неверного количества аргументов.
